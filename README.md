# MazeEscapeAI 🧠🎮

MazeEscapeAI est un projet de Reinforcement Learning dans lequel un agent apprend à résoudre un labyrinthe.

Le projet contient 
- des notebooks d’entraînement et de visualisation ;
- des modèles entraînés au format `.pth` ;
- des assets graphiques pour l’environnement du jeu ;
- des résultats visuels d’entraînement.

## Structure du projet

```text
MazeEscapeAI
├── README.md
├── requirements.txt
├── notebooks
│   ├── notebooks d'entraînement et de visualisation
├── models
│   ├── modèles entraînés .pth
├── assets
│   ├── images du jeu
└── results
    ├── courbes et figures de résultats
